# Kubermatic Academy

Lab manifests and supporting materials for Kubermatic Academy courses on HubLMS.

Each course folder pairs with a video curriculum. The files here are the manifests, scripts, and templates learners apply during the labs — the videos demonstrate them, this repo lets learners reproduce them.

## Courses

| Course | Path | Status |
|--------|------|--------|
| KubeV Beginner | [`kubev-beginner/`](./kubev-beginner) | Initial import |
| KubeOne Practitioner | [`kubeone/`](./kubeone) | Hetzner Cloud labs, before recording |
